# サブスク管理ツール

📱 [ブラウザで利用する](https://sueno2025.github.io/SubscriptionApp/)

---

## アプリ概要
**サブスク管理ツール** は、加入しているサブスクリプションの利用状況を一目で把握できるWebアプリです。  
「増え続けるサブスクの支出を管理したい」という課題を解決するために制作しました。  

- **利用頻度に応じた自動並び替え**  
  加入サービスは「利用頻度（ユーザー入力）」の高い順に表示され、視認性と利便性を向上。  
- **プライバシーへの配慮**  
  電車内などでの使用を想定し、サービス名を個別に非表示にできる機能を搭載。  
- **解約不可フラグ**  
  自動車保険など、契約上解約できないサービスを「解約不可」として管理可能。  

---

## 表示される情報
- 毎月の支払額／年間の支払額  
- 利用頻度3以下のサービスを解約した場合の「想定節約額」  
  （※「解約不可」設定のサービスは除外）  

すべての操作（データ入力 → リスト表示 → 総額・節約額確認）が1画面で完結する **シンプルなUI設計** になっています。  

---

## 制作背景
- 自身のサブスク契約が増え、正確な把握が難しくなったため。  
- 毎月・毎年の出費や「解約した場合の節約額」を直感的に確認できるツールを求めて制作しました。  

---

## 技術選定
- **JavaScript / HTML / CSS**  
- データ保持は **ローカルストレージ** を利用  
  - 登録・ログイン不要で気軽に利用可能  
  - ただし複数端末間の共有は不可（個人のスマホやPCでの利用を前提）  

---

## 特徴
- **1画面完結型UI**：操作ステップを最小化し、シンプルで直感的に利用可能  
- **軽量設計**：DBやサーバ不要で、すぐに利用可能  
- **利用シーンを想定**：公
